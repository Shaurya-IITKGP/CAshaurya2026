# CAshaurya2026

Campus Ambassador Program portal for Shaurya IIT KGP (2026).

---

## Production Deployment (Ubuntu VPS)

This repository is configured for deployment on an Ubuntu VPS running Apache and PM2.

### Prerequisites on VPS

1. **Node.js (v20+) & NPM**
2. **PM2** (`sudo npm install -g pm2`)
3. **Apache2** (`sudo apt install apache2`)
4. **MySQL Server** (`sudo apt install mysql-server`) running on `127.0.0.1:3306`
5. **Git**

### Directory Structure

The repository must be cloned to this exact location on your VPS:
```bash
/var/www/CAshaurya2026
```

If it does not exist, clone it:
```bash
cd /var/www
git clone https://github.com/Shaurya-IITKGP/CAshaurya2026.git CAshaurya2026
```

### Database Setup

Log into MySQL on your VPS:
```bash
sudo mysql
```

Run the following commands to create the database and user (replace `your_mysql_password` with a strong password):
```sql
CREATE DATABASE IF NOT EXISTS `ca.shaurya_db`;
CREATE USER 'shaurya_admin'@'localhost' IDENTIFIED BY 'your_mysql_password';
GRANT ALL PRIVILEGES ON `ca.shaurya_db`.* TO 'shaurya_admin'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### Environment Variables

Before running the deployment script, you must create the backend `.env` file containing your production secrets.

```bash
cd /var/www/CAshaurya2026
cp backend/.env.example backend/.env
nano backend/.env
```

Ensure the following variables are correctly set in `backend/.env`:
*   **Database**: `DB_PASS` (must match the password you set in MySQL)
*   **Email**: `EMAIL_PASSWORD` (SMTP password for `contacts@shauryaiitkgp.in`)
*   **Admin Auth**: `ADMIN_PASSWORD` and `ADMIN_TOKEN` (secure token used for admin sessions)

*Note: The frontend `.env` is automatically generated by the deployment script.*

### Deployment Command

Once the backend `.env` is configured, run the deployment script from the project root:

```bash
cd /var/www/CAshaurya2026
chmod +x deploy.sh
./deploy.sh
```

This script will:
1. Pull the latest code from `master`.
2. Install production dependencies.
3. Build the frontend (`npm run build`).
4. Configure Apache and reload it.
5. Start or restart the `shaurya-backend` process using PM2 on port 5000.

### SSL Configuration

To enable HTTPS, run Certbot for Apache:

```bash
sudo certbot --apache -d ca.shauryaiitkgp.in
```

### Useful Troubleshooting Commands

*   **Check PM2 Status**:
    ```bash
    pm2 status
    ```
*   **View Backend Logs**:
    ```bash
    pm2 logs shaurya-backend
    ```
*   **Restart Backend**:
    ```bash
    pm2 restart shaurya-backend
    ```
*   **Check Apache Config Syntax**:
    ```bash
    sudo apache2ctl configtest
    ```
*   **Reload Apache**:
    ```bash
    sudo systemctl reload apache2
    ```
*   **View Apache Errors**:
    ```bash
    sudo tail -f /var/log/apache2/error.log
    ```
*   **Test Local API**:
    ```bash
    curl http://127.0.0.1:5000
    ```
*   **Test Public URL**:
    ```bash
    curl https://ca.shauryaiitkgp.in
    ```
